  }'

{
  "token": "eyJhbGciOiJIUzI1NiIs...",
  "user": {

================================================================================
STEP 3: CREATE BLOOD BANK REQUEST
================================================================================

Replace TOKEN with your token:

curl -X POST http://localhost:3000/api/realtime-bookings \
  -H "Authorization: Bearer TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "serviceType": "blood",
    "bloodType": "O+",
    "unitsRequired": 2,
    "urgency": "high",
    "location": {
      "latitude": 28.6139,
      "longitude": 77.2090,
      "address": "Delhi, India",
      "zipCode": "110001"
    },
    "notes": "Emergency blood requirement for surgery",
    "hospitalName": "Delhi Medical Center",
    "preferredDate": "2025-12-20"
  }'

Expected Response:
{
  "_id": "booking_id",
  "serviceType": "blood",
  "bloodType": "O+",
  "unitsRequired": 2,
  "urgency": "high",
  "status": "requested",
  "location": {...},
  "createdAt": "2025-12-19T10:30:00Z"
}

================================================================================
NOTES:
================================================================================

1. Make sure the backend server is running on http://localhost:3000
2. Update TOKEN with actual token from login response
3. Update booking_id with actual booking ID from creation response
4. For Windows, use 'curl' directly in Command Prompt (Windows 10+) or use Git Bash
5. For Mac/Linux, these commands work directly in terminal
6. To format JSON responses, install jq: brew install jq (Mac) or apt-get install jq (Linux)
